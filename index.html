Founder's Office at Butter Search

A boutique executive search firm founded by IIM Calcutta alumni, hiring leaders for VC-backed startups. July 2026 to now.

I own client acquisition: deciding which startups to go after, getting founders into a conversation, and turning interest into a hiring mandate. I treat it like a product funnel, with defined stages, a metric for each and a daily update to the founder.

  1. Spot a hiring signal
  2. Reach the founder
  3. Start a conversation
  4. Qualify interest
  5. Win a mandate

  1. Defined the funnel and its metrics

    Five stages from signal to mandate, each with a clear entry rule, so conversion between stages can be tracked and improved.

  2. Prioritised by hiring signals

    Targets are ranked on dated triggers such as a funding round or a leadership hire, so effort goes to startups that need to hire now.

  3. Reworked the first message

    The opener now leads with the company's own milestone, then the pitch, so it reads as relevant rather than cold.

  4. Set a follow-up cadence

    Anyone who accepts but doesn't reply gets a follow-up two days later, so warm leads don't go quiet.

  5. Built the founder's dashboard

    One view of stage counts, conversion, hot leads and what's due today, used for the daily update to the founder.
